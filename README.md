# Homoplankton — Blackwater Archive

夜间黑水潜水拍摄的浮游生物影像档案。108 只生物在纯黑画布上各自独立漂浮，
星尘背景，任意时刻图框之间零相交。点击任意生物可查看高分辨率灯箱。

在线访问：<https://homoplankton.github.io/homoplankton-blackwater-archive/>

也可直接下载 `index.html` 与 `assets/`，双击离线打开。

## 技术要点

- **帧级零相交**：定点迭代预算分配 + 可达投影检查，整个运动过程中不允许任何重叠或碰撞
- **独立轨道漂移**：每张图有各自的 Lissajous 轨道参数（频率/相位/半径），无共享洋流，不同步
- **刷新随机尺寸**：localStorage 记住上次宽度，每次刷新强制 ≥18% 跳变；
  无尖峰区间映射避免钳位堆积，保证「每次都看得出变化」是机制而非概率
- **双层素材**：显示层 108 张（页面浮动图块）+ 灯箱层 108 张（点击放大）
- **纯黑融合**：羽化遮罩起点 55%，非悬停图 92% 亮度，消除方框感

## 仓库结构

```
index.html              档案站页面（单文件，数据内联）
assets/
  display/              显示层 108 张
  full/                 灯箱层 108 张
  assets_manifest.json  id → 本地路径 + 字节数映射
project/archive-run108/ 构建台账与布局验证产物
scripts/
  fetch_assets.py       把 CDN 外链图片取回本地（原样落盘，不重编码）
  relink_archive.py     把页面外链改写为仓库内相对路径，带 4 道校验
```

## 图片自托管

档案站原先引用带 `auth_key` 签名的 CDN 外链，签名已于 **2026-11-24 过期**。
`fetch_assets.py` 在过期前把 216 张图（108 显示层 + 108 灯箱层）原样下载，
`relink_archive.py` 再把页面 URL 改写为仓库内相对路径。

改写采用**文本级 URL 替换**而非重新序列化 JSON：除 URL 字符串本身，
页面其余字节与定版逐字节一致，不引入观感漂移。

改写校验（任一不过即拒绝产出文件）：

1. 替换计数恰为 216（108 图 × 2 层）
2. 改写后无任何外链残留
3. 页面数据块仍可被 `json.loads` 解析
4. 每条记录的非 URL 字段（id / w / h / box / attrs）与原版逐项一致

资源完整性核验结果：108 条记录 / 216 引用路径，缺失 0、冗余 0、
id 唯一、双层分离（`src` ≠ `full`）、JPEG 头尾完整 216/216。
